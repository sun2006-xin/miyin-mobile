# 版本记录

## V1.2 — 2026-10-12

- 接入简体中文与英语的本机翻译、可扩展语言/引擎接口，以及 SQLite 本机翻译历史。
- 修正历史清空后残留当前对话、演示样例混入历史、翻译成功后草稿再次恢复的问题；只在最新本机历史确认该草稿已发送时执行旧版草稿清理。
- 将 ML Kit 管理器改为按需初始化，避免首页启动阶段同步初始化；首次模型请求的同步初始化异常会作为本机翻译错误返回。
- 收紧 AI 对话输入卡片宽度与高度，发送后立即重置长草稿高度，并按模式轮盘真实宽度校准间距。
- 语音识别、语音合成和真实词典数据尚未接入；语音按钮不再显示编造的识别/译文示例。更多语言包与网站下载目录不属于本版。
- GitHub 体验 APK 使用本机构建环境的 Android Debug 签名，不是应用商店发布签名。

## V1.1 — 2026-10-10

- 改进手机端页面渲染路径：流式字幕只更新当前段落，透明像素跳过昂贵的流体着色计算。
- 根据交互活动请求设备高刷新率，并在空闲或应用切到后台时交还系统刷新策略；实际刷新率仍由设备、系统设置和省电模式决定。
- 修正夜间主题下面对面语言控件的颜色，并收敛移动端触控、视口和页面生命周期处理。
- 已在 OPPO PEHM00（Android 12）上完成安装与主题界面冒烟检查；此结果不代表长时间稳定性或 60/90 FPS 达标。
- 本版仍是 UI 与本地交互体验版；真实翻译、数据库、可下载语言包、语音识别和系统音频采集将在后续版本实现。
- APK 使用本机构建环境的 Android Debug 签名，适合当前体验升级，不是应用商店发布签名。

## V1.0 — 2026-10-09

- 首个可独立安装体验的 Android 应用版本，应用标识为 `com.miyin.app`。
- 通过 Flutter 外壳加载随应用打包的 V5 本地界面，保留已确认的主题、布局、AI 对话与球体外观配置交互。
- 集成觅音应用图标与独立 Android 工程，可在 Android Studio 模拟器中运行。
- 当前交付重点是 UI 与本地交互预览；真实翻译服务、模型 API、麦克风和系统音频能力仍待后续实现与设备验收。
- 模拟器体验中仍观察到卡顿，后续版本继续优化渲染流畅度。
