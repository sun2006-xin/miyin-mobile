# English–Chinese offline dictionary data

## Included data

`en-zh-cow-wordnet-3.0.jsonl` is UTF-8 JSON Lines: one English headword per
line, with its WordNet 3.0 synset senses, English definition, Chinese COW
lemma equivalents, and any example phrases present in the WordNet gloss. The
Chinese items are source word equivalents associated with the same synset;
they are not newly written Chinese definitions. No translations were
generated by this project. IPA is kept in the separate, optional English-US
index described below; it is joined only where a dictionary headword matches.

The initial build contains 61,468 normalized headwords and 77,708 distinct
synset senses. All 42,300 Chinese Open Wordnet synsets in the source matched
an exact Princeton WordNet 3.0 synset offset. Coverage and sense ordering come
from those sources and may not match a modern learner's dictionary. This is a
lexical reference for exact headword lookup; it is not a sentence translator,
and it does not promise inflection, fuzzy, or phrase search beyond source
headwords.

## Build and integrity

The output is generated by
[`tool/dictionary/build_en_zh_dictionary.py`](../../tool/dictionary/build_en_zh_dictionary.py)
using only Python's standard library. It checks both source SHA-256 values and
joins COW Chinese lemmas to WordNet English senses by exact synset offset and
part of speech. Adjective satellites are mapped to WordNet's adjective synset
namespace (`-a`), as in COW. It does not use ECDICT or other datasets with an
unclear data-rights chain.

```powershell
python tool/dictionary/build_en_zh_dictionary.py `
  --cow-tab <path-to-pinned-wn-data-cmn.tab> `
  --wordnet-tar <path-to-WordNet-3.0.tar.gz>
```

Generated output SHA-256: `BB00CEBC0C276F8FCBEB742ED709B3675B84FBE8506A7E0ECE00356DC7205944`  
Generated size: 17,845,731 bytes (about 17.0 MiB).

The General American IPA subset is generated by
[`tool/dictionary/build_en_us_ipa_subset.py`](../../tool/dictionary/build_en_us_ipa_subset.py).
It verifies the pinned `en_US.txt` SHA-256, then joins only exact normalized
headword overlaps; the full upstream wordlist is not bundled. Regenerate it
with the source file at the pinned commit:

```powershell
python tool/dictionary/build_en_us_ipa_subset.py `
  --source <path-to-pinned-en_US.txt>
```

Generated IPA index SHA-256: `33439A1342E071959A68939C3096C22E2C5A70C6813C0AAE5B4AD39C3976B9CE`  
Generated size: 822,010 bytes (about 803 KiB).

## Data caveat

COW is a synset-aligned wordnet based on core synsets. Its Chinese equivalents
are concise lexical entries, not exhaustive bilingual dictionary senses.
WordNet definitions and examples are English source text. This is useful for
checking word senses offline, but it should not be described as a complete,
editorially reviewed learner's dictionary.
