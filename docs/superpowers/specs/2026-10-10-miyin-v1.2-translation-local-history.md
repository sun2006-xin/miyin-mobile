# Spec: 觅音 V1.2 中英离线文字翻译与本机历史

## Objective

在已发布的 V1.1 Android 应用中沿用 V5 页面布局，实现一条可用的简体中文与英语双向文字翻译闭环。用户明确下载语言模型后，即使设备离线也能翻译；成功结果保存在本机 SQLite 历史中，可查看、删除单条或清空。翻译、语言、引擎和模型状态使用稳定的语言标签与服务接口，为未来从觅音网站按需下载其他语言包留出替换点。

## Confirmed assumptions and decisions

- V1.2 首发范围是 Android，首个可用语言对为 `zh-Hans ↔ en`。
- 初始运行时采用 Google ML Kit On-device Translation Android SDK。它支持用户显式下载/删除模型并在模型安装后本机翻译；实际模型由 Google/Play Services 管理，不会从觅音自建网站下载。
- Dart 层使用独立的 `TranslationEngine` 与 BCP-47 语言标识，避免界面、数据库与某个模型提供商绑定。V1.2 只开放简体中文和英语；未来网站目录可增加更多语言对与各自包版本、校验值和兼容性信息，但下载、签名校验和安装功能尚未实现。
- ML Kit 按语言管理模型。适配器把 `zh-Hans` 映射到 ML Kit 的 `zh`；英语是内置模型，不可通过 `RemoteModelManager` 下载或删除。中英 pair 就绪只需中文远端模型可用，翻译前仍依据 ML Kit 要求检查源语和目标语模型（跳过内置英语）。
- 不允许云端翻译或自动在线回退。缺少模型时提示用户下载；模型已安装后，翻译本身不需要网络。
- 下载模型默认要求 Wi-Fi；用户可在下载确认中明确允许移动网络。Google 文档建议仅在用户同意时通过移动网络下载模型。
- 成功翻译才写入数据库；翻译失败、取消或缺模型不得生成成功历史。
- V1.1 WebView `localStorage` 继续保留。旧版预览翻译不导入正式翻译历史，避免把固定演示译文当真实翻译；新历史从 V1.2 成功翻译开始记录。
- 本机历史的清空只删除翻译记录，不会删除语言模型、主题或其他偏好。模型管理与历史清除是独立操作。

## Language selection and word lookup UX

- Main-page headers show only the product name `觅音`; screen purpose is communicated by its content and navigation. Face-to-face pause remains available as a 44 px or larger icon button near the microphone with changing accessible labels, instead of a long status sentence under the title.
- Translation mode is an explicit user choice: `句子翻译` or `查词 / 短语`. Sentence translation remains the default. Input length or character count must never choose the mode automatically.
- Available translation choices are the exact directed pairs declared by the active engine whose required models are confirmed as downloaded. The UI must not build arbitrary combinations from a set of languages. If model status cannot be read, show an inspection error rather than claiming that no packages exist. Swapping language directions must verify that the reverse pair is explicitly declared, then distinguish downloaded, not downloaded, unsupported, failed, unknown, and still-checking states; unrecognized statuses must never be labeled as not downloaded.
- The picker offers a direct route to the language section in Settings. When there are no choices, it distinguishes unsupported directions from supported-but-not-downloaded directions. Settings describes only resources that can be managed now, distinguishes Google-managed ML Kit translation models from a future self-hosted package catalogue, and does not imply that the current model is hosted by Miyin.
- Translation mode is visible and touch-friendly, with at least 44 px control height for phone taps. Selecting dictionary mode immediately shows the current dictionary availability, rather than waiting until the user presses Translate; it must not announce that input was retained until the user submits text. When dictionary mode is restored at startup, the explanation and both actions remain fully visible after the native WebView host applies its final layout; they must not sit underneath the fixed input panel.
- ML Kit can translate a single word as ordinary text, but it does not provide dictionary structure such as parts of speech, multiple senses, or usage examples. Until a licensed offline dictionary package and provider exist, dictionary mode retains the input, explains that the dictionary is unavailable, and does not fall back to sentence translation or a network service. The user may explicitly switch to sentence translation.
- A dictionary package is a separate capability and resource from a translation model. Future support requires its own package language metadata, source/licence, version and checksum, and a result contract for headword, pronunciation, part of speech, senses, and examples.

## Tech stack

- Flutter 3.47.2 / Dart 3.13.2；现有 V5 页面继续由 `webview_flutter` 加载。
- Android Kotlin Platform Channel 调用 Google ML Kit Android Translation SDK (`com.google.mlkit:translate:17.0.3`)。
- SQLite 由 `sqflite` 提供；`sqflite_common_ffi` 用于 Windows 上的真实 SQLite 数据层测试。ML Kit 的真实模型状态由 Android `RemoteModelManager` 查询；数据库的模型包元数据表预留给后续自托管下载器，不为 ML Kit 虚构模型版本或下载大小。
- JSON RPC over `JavaScriptChannel` 连接 V5 页面与 Flutter；所有数据库和模型操作异步执行。

## Code style

领域层只接收规范语言标签和请求对象，不识别 UI 文案。模型提供方实现窄接口；SQLite 的异步读写不放在 WebView JavaScript 或 Flutter 构建方法里。

```dart
abstract interface class TranslationEngine {
  Future<Set<TranslationLanguagePair>> getSupportedLanguagePairs();
  Future<TranslationModelInfo> getModelInfo(TranslationLanguagePair pair);
  Future<void> downloadModel(TranslationLanguagePair pair, {required bool wifiOnly});
  Future<void> deleteModel(TranslationLanguagePair pair);
  Future<TranslationResult> translate(TranslationRequest request);
}
```

生产逻辑只实现当前切片需要的 `zh-Hans` 与 `en`。UI 使用显示名“简体中文”“English”，数据库和接口使用稳定标签；不得以“中”“英”等缩写作为存储键。

## Testing strategy

- **Domain unit tests**：标准标签、非法语言/空文本拒绝、交换方向、中英请求快照、引擎缺模/失败不生成结果。
- **SQLite tests**：真实 SQLite 内存库；版本化建表与迁移；成功原文/译文/方向/时间/引擎元数据持久化；单条删除、清空、排序和分页；重开数据库后仍存在。
- **Bridge tests**：请求 ID 配对、未知方法拒绝、JSON 参数验证、异步结果和失败编码；网页预览模式不调用原生服务。
- **Android integration**：模型下载前后状态；明确下载网络条件；模型缺失不自动下载；成功翻译后才写库。
- **Device acceptance**：OPPO PEHM00 Android 12 与 Android 模拟器；执行双向、飞行模式、短长文本、重启、清空历史、失败恢复；记录首译和热译耗时及 UI 响应。
- **UI acceptance**：V5 Mint/Mist/Night 三主题、320/360/393dp 窄屏、键盘弹出、历史详情滚动、Voice/face 预览功能无回归；错误与模型状态用文字+图标表达。

## Boundaries

- **Always**：保留 V5 页面的视觉骨架；WebView 不整页重建；数据库 IO 与模型调用异步；用户文本保留至翻译成功；所有错误提供恢复方式；历史只存成功结果；测试先于实现。
- **Ask first**：改变 V1.2 首发语言范围、将模型默认下载切到移动网络、使用远程 API/上传用户文本、清除 V1.1 原始数据或迁移并展示演示内容。
- **Never**：把固定示例字符串当译文；静默调用云端；声称 V1.2 已从觅音网站分发模型；把整份模型权重写入数据库；清理用户已有 WebView 存储；承诺未经设备测量的 60/90 FPS 或准确率。

## Success criteria

1. 用户可以在现有翻译页选择 `简体中文 ↔ English`，一键交换方向并提交文字。
2. 缺少简体中文远端模型时界面显示明确的离线模型状态和下载操作；英语显示为引擎内置且已就绪；未经用户操作不下载。
3. 模型下载后，飞行模式下两个方向都能产生真实结果；无静默云端回退。
4. 点击翻译后立即显示轻量加载状态；期间不重复提交；失败时保留原文；成功时展示原文与译文。
5. 成功结果保存到本机数据库，退出并重启应用后仍能查看完整原文、译文、方向和时间；如果翻译成功但数据库写入失败，仍展示译文并明确告知历史未保存。
6. 用户可删除单条翻译记录或清空所有翻译记录；删除历史不会删除模型、主题或 AI 历史。
7. 现有 V5 外观、语音球、面对面页面、主题和页面切换继续工作；夜间主题控件文字和系统栏保持可读。
8. Android debug 编译、Flutter 测试与分析通过；OPPO 和模拟器按上述矩阵完成手机适配核验。对其他设备的性能仅作明确范围内的推断。
9. 使用 ML Kit 时，在译文附近准确显示“Google ML Kit · 本机离线”，不得称为“Google 翻译”；模型管理说明标明模型由 Google Play 服务管理，并说明翻译文本在设备上处理、不发送到觅音服务器。
10. 版本仅在本切片验收后提升为 `1.2.0+3`，发布标记为 `V1.2`。

## Additional release gates from review

- 人工审核固定的中译英、英译中样例，记录译文质量结论后再决定 V1.2 是否可发布。
- 在目标设备覆盖下载取消/失败后的恢复与重试；Google Play 服务不可用时显示可理解的错误。
- 升级验收分别确认 V1.1 WebView 示例仍存在，新的 SQLite 翻译历史为空且没有导入演示内容。
- 任何 V1.2 release APK 必须改为受控的正式签名配置，并验证同签名覆盖安装及本机数据保留；当前 debug build 不满足该门槛。

## Deferred scope

- 从觅音自建网页/CDN 获取签名语言包、断点续传、TUF 或等效签名清单、校验/原子安装。
- 实际启用其他语种、繁体中文、语音识别/合成、面对面对话真实录音、字幕、OCR、悬浮球、AI 聊天和云同步。
- iOS 翻译运行时与 iOS 真机验收。
- V1.2 模型下载体积和翻译质量的最终产品门槛；需先在目标手机测量并审核双向样例。
