# 觅音翻译体验与词典首版设计规格

## 目标

在觅音现有 V5 手机界面上整理翻译入口和对话状态呈现，并规划独立的词典查词页面及离线资源管理入口。首版先交付可供用户评审的页面设计；词典内容以正确性、来源和许可可追溯为上线前提。

## 已确认的产品决定

- 翻译页的模式入口使用输入框左侧紧凑胶囊，默认显示“句子⌄”；点击后选择“句子翻译”或“词典查词”。模式始终由用户明确选择，不根据输入长度猜测。
- 主要页面顶部只显示产品名“觅音”；不重复显示“AI 对话”“视频字幕”等用户已能从页面内容判断的长标题或说明。
- 翻译首页不常驻显示“离线包已就绪”等模型状态。用户到资源管理页面查看模型状态、下载或移除资源。
- 翻译语言选择只列出当前方向已安装且可实际执行的语言组合；反向组合独立检查，不因一种方向可用就推断另一方向可用。
- 词典是独立能力和独立页面，不能将普通机器翻译结果伪装成词典释义，也不能在查词失败时静默切换到句子翻译。
- 用户优先要求词条准确。首版页面可以先供用户评审；正式显示词条前，必须有经核验的数据源、许可、版本和出处。
- 当前手机翻译运行时实际支持的语言能力以代码和引擎返回为准。未接入的语种、词典、ASR 或 TTS 资源不得作为已可下载的选项展示。

## 范围

### A. 翻译首页

- 保留现有觅音视觉语言和双向中英翻译主流程。
- 将占据整行的大型“句子翻译 / 查词短语”分段控件替换为输入栏左侧的“句子⌄”模式胶囊；点击打开简洁、易点选的两项选择面板。
- 模式胶囊按当前页面/模式动态显示“句子⌄”或“词典⌄”。切换模式不自动提交、不清空草稿；选择“词典查词”时进入独立词典页，并将翻译页草稿填入词典搜索框但不自动查词。词典页可选择“句子翻译”返回翻译页，仍保留草稿。
- 移除页面上长期占位的模型就绪提示；需要时通过资源管理入口查看。
- 语言选择器只列当前已安装且可执行的有向语言对；反向方向单独查询状态。语言对未就绪时提供前往资源管理页的入口，不出现在可直接使用的选择项中。
- 明确选中“词典查词”后，页面立即显示词典能力状态；若没有可用词典数据，保留用户输入并说明暂无可用词典数据，提供前往资源管理的入口。不得发送翻译请求或生成类似释义的替代内容。

### B. 面对面对话

- 移除语言栏下面永久显示的操作说明；状态提示靠近麦克风控制或当前对话条目显示。状态至少区分待机、按住聆听、松开后识别、翻译、完成、失败和权限拒绝。
- 快速松开后再次按住，或识别/翻译较慢返回时，旧操作的迟到状态不得覆盖新操作；释放后及时清除“正在聆听”。
- 麦克风、暂停/继续控制和侧边模式轮盘应有独立触控区域，不得遮挡或重叠；手势与按钮触控目标需可分别操作，主要按钮触控目标不小于 44 dp。
- 模式轮盘保持固定视觉样式；切换功能时不得意外切换成玻璃/海玻璃材质。
- 临时成功提示约 1.5–2 秒后淡出；仍在进行的录音/翻译状态持续显示到状态改变；需要用户处理的错误持续显示直到关闭或恢复。

### C. AI 对话

- 使用单列流式字幕，不制作传统左右聊天气泡；用户与 AI 内容都靠左排列。用户转写字号和颜色弱一档，当前 AI 回复最清晰，较早内容逐渐弱化。
- 内容列最大宽度先按可用内容区约 90% 设计，而非给每条消息套固定气泡宽度；在 360 dp 窄屏验证中英混排和长文本完整换行、可滚动、无横向溢出。预览后可按用户反馈微调。

### D. 离线资源管理

- 首版建议从设置进入独立的“离线资源”整页，避免长列表塞进小弹窗；没有已获许可的词典数据或有效下载目录时，明确显示“暂不可下载”，不制造下载按钮或可用语种。
- 使用纵向滚动的紧凑资源行，展示资源类型、语言或语言对、提供方、版本/来源（若运行时可确认）、大小（若可确认）、当前状态以及当前确实支持的操作。资源状态分别表达引擎能力、目录/来源可用性、安装状态和当前操作状态；未知、检查失败、未安装、已安装和下载中不得合并成一个布尔值。
- 列表按真实目录渲染；手机 UI/列表压力验收可用 20 项以上的测试夹具，但测试夹具不能出现在正式用户资源列表中。移除前说明受影响资源和共享依赖，取消不改变任何资源；确认后只执行提供方声明的操作。
- 对 ML Kit 等由平台/提供方管理的模型明确标注管理者；不得把它们说成由觅音自有网页提供。
- 未来自托管目录可以由清单驱动，至少需要资源类型、语言对、版本、目标平台/运行时、依赖、文件大小、校验值、签名/发布者、来源及许可信息。清单格式和下载器不属于本次页面规格的必然实现范围。

### E. 词典页面

- 独立页面采用词典阅读结构：搜索框、词头、音标/读音（数据确实提供时）、词性、分义项、例句/搭配、收藏与查词历史。
- 每条结果应能看到或打开来源、词典版本/数据版本及许可归属；拆分、删改或本地化内容时记录修改说明。
- 搜索结果必须来自词典数据提供方的结构化查询；不允许调用句子翻译服务来生成词性、义项、例句或发音。
- 匹配状态至少区分精确词头、词形还原、固定短语匹配、未找到、不支持的语言/查询和查询失败。用户原始输入始终保留；整句在词典模式下没有匹配时仍显示未找到，不自动改成句子翻译。
- 已安装词典数据后的查询默认在本机离线完成；下载词典数据需要联网，但查词内容不上传。若未来提供在线词典服务，必须作为独立且由用户主动选择的 Provider。
- 当没有配置或安装可用词典时，显示明确空状态和“查看词典资源”入口，直接定位到词典资源分组；如果没有有效目录/已授权数据，则明确显示“暂不可下载”。查无词条、数据损坏、查询失败分别显示不同状态，不互相伪装。
- 页面可以先以空状态完成布局预览。用于页面排版的任何样例条目必须来自已核验且允许展示的数据，并清楚标明来源；不制作伪造词条作为真实演示结果。

## 词典数据正确性与来源规则

- 词典词条必须绑定可识别的数据源、版本、语言方向及许可元数据；无法追溯到来源的结果不展示为权威释义。
- 不因“只是抄录”而复制牛津词典内容。牛津数据只有在获得适用 API/数据集授权并遵守具体合同后才可使用；样例或试用条款不等于可把词条打包进觅音分发。
- 可以评估具有明确再利用许可的词典数据，但每个来源要逐项核对商业/非商业限制、署名方式、相同方式共享要求、衍生作品条款及可再分发范围。兼容性未确认前不得导入、打包或展示内容。
- 词典服务与翻译引擎使用独立接口；建议查询合同包含标准词头、语言、匹配状态、发音、词性、义项、例句/搭配、来源/版本及许可标识。缺字段时不虚构补全。
- 可分发词典包保留所需许可与署名文本；混合来源时每条词条可追溯具体来源，并记录本地化、删改或其他修改状态。
- 资源下载和词典数据本地存储遵守用户明确选择；清理词典数据不应隐式删除翻译模型、偏好或翻译历史。

## 架构边界

- 普通翻译使用既有 `TranslationEngine` 路径；词典查词使用独立 `DictionaryProvider` / `DictionaryService` 和独立 RPC 方法，例如 `dictionary.lookup`。
- 前端的模式切换只更改用户选择，不在 Web 层绕开原生服务或改写为普通翻译请求。
- “当前已安装”“当前提供方支持”“可下载”“将来计划支持”必须是不同的资源状态；界面只显示代码实际可管理的资源。
- 资源管理目录与当前 ML Kit 的系统管理状态分开建模，不能仅靠数据库中一条通用包记录声称能够下载、移除或校验实际模型。
- 资源卡片和操作单位依据 Provider 实际管理的资源及共享依赖决定；不能假设每个语言对对应一个独立文件。可执行语言方向由其实际依赖资源状态推导，内置或不可下载的模型不显示虚构下载/删除操作。

## 验收标准

1. 翻译页使用紧凑模式入口，状态在“句子⌄ / 词典⌄”之间明确切换；触控目标不小于 44 dp，模式切换不自动提交或丢失草稿。
2. 翻译页语言选择只列当前有向语言对已安装且可运行的方向；反方向独立检查。首页不常驻展示模型就绪条。
3. 所有主页面顶栏只显示“觅音”；页面类型由内容区表达。
4. 面对面对话覆盖待机、按住聆听、松开后识别、翻译、完成、失败、权限拒绝和快速重启录音；迟到回调不得覆盖新状态，麦克风与暂停等控件不重叠，轮盘外观稳定。
5. AI 与用户内容按单列字幕流靠左；用户转写弱化，AI 当前回复突出；在 360 dp 窄屏检查长中英文本完整换行、可滚动和无横向溢出。
6. 资源管理页只显示真实能力/目录/安装/操作状态；在 20 项以上测试夹具下列表可滚动、长名称不截断关键操作；测试移除取消及确认和共享依赖提示。夹具不显示在正式资源列表。
7. 词典模式没有可用数据时显示空状态并保留输入；入口直接到词典资源分组且不会假示有可下载数据。查词永不回退到普通翻译，并区分精确词头、词形、短语、未找到、不支持和失败。
8. 任何可见词典内容都能追溯到获准的数据源、数据版本及所需署名；来源或许可不明时不进入正式数据包。
9. 首版页面在 OPPO 手机与窄屏 Android 模拟器上检查系统状态栏/底部手势安全区、键盘弹出/收起、滚动、浅色/深色主题及控件触达；系统字体放大至 1.3× 时无关键内容遮挡。本轮按竖屏验收；若应用支持旋转则另测横屏。未验收前不声称手机端适配完成。

## 不在本规格承诺的范围

- 复制或分发牛津词典内容；实际词典供应商及数据包定稿。
- 宣称支持当前代码没有接入的更多翻译语种、语音包或词典包。
- 自托管语言包网站、签名目录、断点续传、下载器和跨平台安装器。
- 云端查词、自动联网回退、自动下载资源或上传用户输入。
- 本规格提交本身不代表 UI 已实现、词条数据已授权、APK 已构建或真机已验收。

## 实施前置与验收流程

1. 用户审阅并确认本规格。
2. 编写分阶段实施计划，明确页面预览、数据源评估、独立服务接口、测试和设备验收边界；用户审阅后再开始代码实现。
3. 先交付翻译页与词典页的可预览首版，供用户按体验提出视觉和布局调整。
4. 词典内容接入单独过数据来源和许可核验；在来源未通过前，页面只展示空状态，不填充虚构数据。
5. 每个实现阶段进行相应代码验证和手机适配检查，分别报告源代码、构建和真实设备证据。
