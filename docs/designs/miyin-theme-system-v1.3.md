# 觅音界面主题系统 V1.3

## 设计目标

把用户提供的六套主题稿转换成适合实际手机操作的界面色板。每套主题都作用于整个应用，包括主页、翻译记录、面对面对话、AI 对话、词典/资源页、设置页、浮层和按钮。保留原有的“薄荷全息”“冷雾 · 铅灰”“石墨夜 · 银灰”，并为新色板使用独立 ID，避免覆盖用户已保存的选择。

主题稿中的纸张、金属、玻璃、植物、云雾和石材质感作为轻微背景氛围处理；文字和可点击区域始终使用不透明表面、清晰边框和系统字体，避免大面积纹理降低可读性或拖慢低端设备。

## 主题规则

- 背景色用于应用画布和外围预览区域；卡片色用于对话、输入区、浮层、设置面板和列表。
- 主色用于主要操作、选中状态、图标和焦点提示；强调色用于局部装饰、主题标题线及轻微高光。
- 文字色在浅色主题下保持深色，在深色主题下保持浅色；按钮文字按主色对比度单独指定。
- 对话双方继续用柔和的背景差异区分；翻译原文与译文不依赖颜色表达额外语义。
- 主题选择沿用现有本机存储键 `theme`，即时生效并跨应用重启保留。
- 保留现有球体材质选择与主题独立，避免切换色板覆盖用户的球体偏好。

## App 图标

- 以用户提供的方形完整 Logo 图作为 iOS 与旧版 Android 的主图标母版，输出各平台要求的像素尺寸。
- Android 8.0 以上使用自适应图标：由用户的透明前景标记叠加蓝青渐变背景；单色层使用用户提供的 Android 单色版本。前景缩放到自适应图标安全区域内。
- 原始 Logo 文件保留为来源资产；平台尺寸文件仅为确定性裁切/缩放，不重绘图形。
