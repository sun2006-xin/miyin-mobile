# V1.3 主题与图标实施简报

## 目标

在觅音手机应用“设置 → 显示与偏好 → 界面主题”中，为用户提供设计稿里的六套可选色板；保留现有三种主题与其已有本机偏好。将用户提供的新 Logo 用作 Android 与 iOS 启动图标。

## 用户行为

1. 用户在“界面主题”卡片里可看到九个选项及各自四色预览：背景、卡片、主色和强调色。
2. 点击任意选项后，主题名、主题色与 app 主题色即时更新；选择在现有 `theme` 本机存储键中持久化。
3. 主题作用于全部应用页面、消息气泡、输入/按钮、导航、设置、历史与弹层，不影响 AI 球体的独立材质设置。
4. 旧版本存储值 `mint-holographic`、`mist`、`night` 保持有效；未知值回退到当前默认“薄荷全息”。
5. Android 新版与旧版启动器图标均使用新 Logo；Android 8.0+ 可提供前景、背景及单色自适应图层。iOS 图标集包含现有目录要求的每个尺寸。

## 验收重点

- 六套新主题颜色与用户提供色板一致，浅色/深色分类正确。
- 320px、360px 与常见手机宽度下，主题选项不横向溢出，长主题名可读，设置内容仍可滚动。
- 至少检查主页、翻译、面对面对话、AI 对话、设置与历史页在浅色和深色主题下的文字/控件对比度。
- 重启后主题仍为用户最后选择；从旧版偏好升级不会重置主题。
- 设备启动器显示新图标；Android 自适应图层在安全区内完整显示。
- Android/iOS 图标资源尺寸与清单匹配；当前 Windows 环境不能替代 iOS Xcode 编译验证。

## 边界

此次只完成应用内的主题色板与品牌图标，不引入大尺寸纹理背景，也不改变翻译、词典、语音服务或球体材质功能。
