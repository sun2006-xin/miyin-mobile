## 目录用途

| 目录 | 内容 |
| --- | --- |
| `brand/` | 品牌与当前宣传图，部分图标为历史概念 |
| `ux-design/` | 外观与交互约束 |
| `designs/` | 已跟踪的历史界面方案，用于理解演进 |

| `release/`、`releases/` | 发布证据与版本说明 |
