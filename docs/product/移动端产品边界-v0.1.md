# 觅音：Android 同传产品边界与阶段门 v0.1

状态：Android 优先方向与 V4 视觉基线已确认；应用名定为“觅音”；V5 交互网页预览已完成并进入审阅。本文记录产品和平台边界，不表示 Android 源码或真实 AI/音频能力已实现。

## 品牌方向

- 应用名称：觅音。
- 图标概念 v9 已由用户确认：白色玻璃质感圆角底块；抽象黑色线条勾勒侧面唇形，不做写实质感或填色；左侧黑色声线舒展弯曲，隐约形成耳朵意象。确认 PNG 为当前品牌视觉基准，后续启动器资源按 Android 尺寸规范另行导出。
- 启动动画方向：嘴唇发声，声波传到耳朵，随后出现“觅音”和宣传语；宣传语文案及动效细节待确认。
- V4 手机端预览是已确认的布局与视觉基线，原版保留不变；V5 在独立目录中沿用其主题、主页面、模式转轮和语音按钮，扩展 AI 对话与历史交互供审阅。旧的 V1 交互预览仅留档，不作为实现依据。

## 产品范围

- 独立 Android 同传 App，先服务面对面陌生人交流，也覆盖视频学习、直播和会议。
- App 导航方向：同传、AI 助手、会话、我的。AI 助手同时是通用聊天入口。
- 对话模型统一承担解释、总结、复盘与工具协作；不另做独立的“AI总结”页面。
- 手机与阅读器共享 Agent/会话核心；麦克风、Android 系统播放音频、PiP 等由平台适配器提供。
- Windows 桌面端暂缓，后续复用共享核心并单独实现桌面能力适配。

## 已确认的交互方向

- 面对面：按住说话为默认，也提供免按住收音；支持切换语言方向，译文可自动播报、点按朗读或静音。
- 媒体同传：用户主动选择麦克风或其他 App 音频；PiP 用于跨 App 查看字幕。
- AI 对话：允许普通聊天；同传记录作为显式附件进入本轮上下文，用户可移除。
- 模型：支持配置 API 厂商、地址、密钥和模型 ID；连接与能力测试后再允许选择。Agent 模型与翻译模型各自配置，远程使用要由用户显式选择。

## 工程阶段门

1. 交互预览：V4 视觉基线已确认；V5 网页预览覆盖 AI 多轮会话、实时语音状态、回答朗读/复制/分享/重试、模型不可用时保留输入且不静默切换、AI 历史搜索与详情、继续/改名/分享/删除，以及用户显式选择并发送历史上下文。
2. 工程骨架：搭导航、模块边界、共享领域接口、状态模型与占位交互；不接真实录音、ASR、翻译、TTS、模型 API。
3. 功能薄切片：一次实现一个可见功能，先验收交互，再接平台或模型服务；覆盖拒权、中断、错误和恢复。
4. 验收：在模拟器与目标 Android 设备检查核心路径、隐私提示、触控尺寸、旋转/窄屏和恢复流程。

## 待确认

- 用户对 V5 新增 AI 对话与历史交互的最终审阅结果。
- 面对面页面是否需要 180° 屏幕翻转。
- Android 应用包名。
- 共享 Flutter/Dart 与 Rust Core 的依赖/版本化方式。
