# 译学移动端产品边界与阶段门 v0.1

状态：Android 优先方向已确认；本仓库现处于交互预览阶段，页面布局仍待用户确认。

## 范围

- 独立 Android 同传 App，先服务面对面陌生人交流，也覆盖视频学习、直播和会议。
- App 导航提案：同传、AI 助手、会话、我的。AI 助手同时是通用聊天入口。
- 对话模型统一承担解释、总结、复盘与工具协作；不再做独立的“AI总结”页面。
- 手机与阅读器共享 Agent/会话核心；麦克风、Android 系统播放音频、PiP 等由平台适配器提供。
- Windows 桌面端暂缓，后续复用共享核心并单独实现桌面能力适配。

## 已确认的交互方向

- 面对面：按住说话为默认，也提供免按住收音；支持切换语言方向，译文可自动播报、点按朗读或静音。
- 媒体同传：用户主动选择麦克风或其他 App 音频；PiP 用于跨 App 查看字幕。
- AI 对话：允许普通聊天；同传记录作为显式附件进入本轮上下文，用户可移除。
- 模型：支持配置 API 厂商、地址、密钥和模型 ID；连接与能力测试后再允许选择。Agent 模型与翻译模型各自配置，远程使用要由用户显式选择。
- UI：温和中性色与蓝绿色强调，浅色/深色模式；聊天交互参考主流 AI 对话工具，其他页面采用译学自有设计系统。

## 工程阶段门

1. 交互预览阶段：确认屏幕结构、按钮位置、文案、各状态和异常入口。
2. 工程骨架阶段：搭导航、模块边界、共享领域接口、状态模型与占位交互；不接真实录音、ASR、翻译、TTS、模型 API。
3. 功能薄切片：一次实现一个可见功能，先验收交互，再接平台或模型服务；覆盖拒权、中断、错误和恢复。
4. 验收阶段：在模拟器与目标 Android 设备检查核心路径、隐私提示、触控尺寸、旋转/窄屏和恢复流程。

## 待确认

- 面对面页面是否需要 180° 屏幕翻转。
- 正式商品名、Android 启动器图标和应用包名。
