# 本地语音与外接聊天模型边界

用户决定：只考虑本地语音部署，外接API用于增强聊天与工作能力。对应候选版本1.6.0-preview+56。

- ASR语音识别与TTS合成均在设备本地运行，不提供自动回退云端语音服务的路径。
- 外接聊天/工作模型继续可选；语音交互时本机识别得到的文字可按聊天隐私设置交给所选模型，回答再由本机合成。本地千问仍保留为离线选项。
- 移除+55新加的在线TTS子页、凭据通道和运行时适配；不触碰聊天API凭据与模型配置。+55提交及文档作为历史保留，不将已试验的在线功能混入当前设置。
- 保留tool/performance的本地合成基准，以及Melo/Matcha的受控对比。当前Melo中文合成慢于播放，尚未达成实时聊天；Matcha候选有速度余量，但音质覆盖和可分发条件尚未完成核验，因此没有擅自替换内置音色。

后续只沿本地路线推进：先核对快速模型的中文发音与长短句连续性，再比较音色、英文/混合语言覆盖、内存与初始化时间，选择合适的模型接入。预热、前瞻缓冲、单轨道和缓存继续作为辅助，不能用缓存结果冒充新回复实时效果。

本轮验证结果与APK位置记录在D盘本地交接中。在线语音协议的模拟测试已随撤下功能移除；继续执行现有离线语音与聊天回归，不称实时性已经修复。
