# speech59：识别首轮对照与开源前能力盘点

本轮是实际设备独立基准和只读代码审查，不是整机验收，不含新APK、推送、合并或公开仓库。维持已确认范围：翻译/面对面朗读暂不替换；AI聊天试验快速TTS；ASR/TTS留在本地。

## ASR首轮真机结果

OPPO PEHM00 Android12，CPU2线程，greedy，自动语种；当前APK相同原生库。Whisper base int8与Qwen3-ASR0.6B int8各独立进程，一次加载后按相同顺序解码6段完整音频。无VAD切段、无并发聊天、无麦克风。中文/英文为speech58已生成的测试语音；德法日俄为官方包内样本。仅少量样本，不能当总体准确率排名或真实口音验收。

初始化base1.749秒，Qwen7.053秒。不同模型解码流程不同，无额外推理预热；不把初始化差异混入解码。不能将上述离线整段解码时间称为实时首字延迟。Qwen首轮没有满足全面替换条件。

官方压缩包878,702,423字节，SHA256 `393f8a14e2f5fb96746aaab342997a40641001fbd5bf9592a080a8329178ee96`；解压整体1,000,089,677字节（含测试音频）。0.6B不等于手机小体积。模型仅保留测试目录，未加入应用资产或LFS。设备测试目录 `/data/local/tmp/miyin-asr59`，没有清除应用数据。

证据：`output/speech59/asr-base.log`、`asr-qwen.log`；法语单独与英文后重复测试记录为`fr-alone.log`、`fr-after-en.log`。独立C工具为 `tool/performance/android_asr_benchmark.c`，已由NDK编译并真机执行。

复测结果：法文单独进程连续两次、另一个进程英文后一次，均重复异常短输出（约2.09–2.15秒），原始字节另存`.bin`。因此当前转换模型/原生库/设备组合未通过法文测试，不能作为新默认；并非据此判断所有Qwen版本均不能识别法语。未修改应用模型或翻译朗读。

## 已有产品能力

- 本机/电脑Ollama/多厂商云聊天配置、模型显示名单、流式回答、停止/续写/重生成、SQLite会话历史。
- 应用主动搜索、读公开网页、显示来源；TXT/Markdown、选定翻译/同传历史、直接图片输入。OCR是用户可选入口，不是所有图片被强制转文字。
- 语音ASR→模型→TTS、手动停止与退出处理。翻译、面对面、图片/文章翻译、同传和录制等已有实现；本轮未重新做这些功能的整机回归。

## 开源准备缺口

1. 根项目LICENSE未跟踪，需要用户确定源码许可；公开仓库不自动授权他人使用。
2. THIRD_PARTY_NOTICES明确当前sherpa原生库含GPL eSpeak/piper；需核对实际二进制、源码和相应发行义务，或采用排除这些组件的构建。GPL不等于不能开源，但不能忽略义务。模型换成MIT不会从原生库移除依赖。
3. 模型/词典/字体/原生依赖分开列版本、来源、hash、完整许可和转换说明；Whisper转换分发条件的现有待审项需关闭，Supertonic权重OpenRAIL-M不能标MIT。
4. 根README仍V1.5.1并称AI预览，appREADME还写ASR/TTS未实现；需按当前事实重写。
5. 无已跟踪GitHub工作流；需干净目录构建和CI，固定依赖及可复现资源准备。不是本轮已执行事项。
6. release当前debug签名；需正式签名/升级策略、ABI/系统版本/设备范围。签名私钥不进仓库。
7. LFS9个模型对象约2.2GB；清楚区分轻量源码、完整离线构建和成品APK，避免克隆后不知缺哪些资源。
8. 已有忽略规则和AndroidKeyStore；仅文件名检查未见典型凭据文件，不是全Git历史秘密扫描，公开前仍需检查。

## 建议后续版本顺序

第一阶段语音体验与核心稳定；第二阶段聊天/记忆/搜索/资料和服务兼容；第三阶段开源可复现、许可、CI、签名、支持矩阵与已知问题。第一开源版不必等待完整手机Agent。Agent先做搜索/网页/选定历史/会议纪要等只读工具、有界执行、可见步骤和取消，再另行规划跨App写入操作。
