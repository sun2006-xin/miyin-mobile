# DeepSeek 文字聊天首轮候选版

状态：基础设置开发候选。用户明确先不填写 API Key，优先完成模型选择、服务配置和隐私设置。真实服务验收暂缓，不是新的稳定发布。

## 已实现的代码

- 沿用聊天消息流、输入框和历史界面；Android 使用真实 DeepSeek 通路，浏览器预览保留模拟通路。
- 服务配置使用原生窗口。密钥由 Android Keystore AES-GCM 加密保存，不进入网页 RPC、localStorage 或导出文字。
- 连接检查仅调用官方模型列表，不发送聊天记录；模型来自账户实际可用列表。
- 普通文字模式、流式增量、取消、手动重试、重新生成；错误和停止保留已收到文字，不自动重发或切换服务。
- 每次生成使用独立请求编号和网络连接；晚到事件不能覆盖被停止的回答。
- 会话快照写入 SQLite；网页旧会话导入一次，迁移成功后移除旧网页副本；重启后的未完成回答标为可重试。
- 关闭保存历史时，新增对话仍走既有临时会话逻辑。
- 模型选择、服务配置、AI 隐私分别打开独立窗口，均有返回和保存。模型预设和自定义 ID 无需密钥即可保存，账户可用性不伪装成已验证。
- 远程 AI 发送默认关闭；关闭会话上下文后仅发送当前用户消息。隐私偏好保存在本机，与原有历史保存开关同步。
- 附件、会议上下文、语音对话和回答朗读尚未接入，Android 显式提示后续阶段，不生成模拟回答。

真实连接、回复内容、首字延迟、停止后网络取消、断网恢复，以及真实消息的跨重启保存，需要用户在手机配置密钥后核对。构建和设置窗口可打开，不等于这些场景已经验收。

## 使用

1. AI 对话输入区点模型按钮，或进入“设置 → 模型与服务 → 默认 AI 模型”，选择模型并保存；本轮无需填写密钥。
2. “模型服务商 → 服务配置”查看官方服务和连接状态，密钥可稍后填写。
3. “隐私选择 → 隐私设置”调整远程发送、携带上下文、本机保存。
4. 未来进行真实联调时再填写密钥、检查连接，并主动开启远程发送。
