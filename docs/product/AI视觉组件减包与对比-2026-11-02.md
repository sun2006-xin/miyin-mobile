# AI 视觉组件减包与对比

候选版本：1.6.0-preview+53，承接 +52。保留同一个 Qwen3.5-2B 主模型、原图接口、768 图片 token 上限、1024 应用输出预算和现有界面。本轮不修改模型身份提示、答案或知识，不降低图片分辨率上限。

## 变更与归因

1. 视觉组件从上轮固定版本 F16 转为本地 Q8_0 派生产物。文件从 668227264B 减为 361518784B，减少 306708480B（45.9%）。转换有量化误差，不能称为无损。
2. 修复显式 android-arm64 构建仍混入其他架构依赖的问题。+52 APK 中 armeabi-v7a 压缩条目 18659721B、x86_64 条目 22801212B；本机 LLM 与 Flutter 本来只包含 arm64 运行库。仅对显式 arm64 构建启用 NDK abiFilters，其他构建目标不被这个条件改变。
3. 保留固定文件校验：Q8 原生复制检查使用新的长度和 SHA；完整源文件、转换工具及派生产物记录在 vision-manifest.json。旧 F16 保留于 Git LFS 历史、+52 包及本地比较基线。

## OPPO 受控比较

同一 OPPO、原生 d854d98 运行库、同一主模型与两个无文字合成样本。顺序 F16→Q8→Q8→F16，每次新建独立进程；同 prompt、seed42、temperature0、cache_prompt=false、图片上限768和编码批次256。比较输出预算统一128，应用仍1024；不能把受控耗时当作整机完整回答时间。

| 首输出样本 | F16（毫秒） | Q8（毫秒） |
| --- | --- | --- |
| 绿色三角/紫色圆 | 42828、36546 | 34578、34484 |
| 三色柱状图 | 35516、35390 | 35828、36422 |

- 图形的形状、颜色两种格式各两次均正确。柱状图最高蓝柱均被误判成红柱，最短黄柱判断正确。这个图表样本是两种格式共有的失败，不能列为通过。
- 服务日志8次均 truncated=0，无空答案。SSE usage为空，未据此计算吞吐。已审阅完整答案及本地服务日志。
- 图形样本有降低，图表没有改善；缺少每轮温度记录且样本少，不能声称普遍提速。保留 Q8 的直接依据是可测量的体积收益、实际加载及有限语义样本未观察到新增回退。
- 单次过程中读取到CPU热区约52°C，ABBA不完全消除热状态影响。后续严谨速度结论需要记录每轮温度、完成原因及更广样本。
