# AI 实时语音接入与本地合成对比

> 后续决定：用户明确语音识别与合成只考虑本地部署，只有聊天/工作模型通过API增强。+56已撤下本文描述的+55在线语音运行时与入口；本文保留为历史试验记录。本地性能对比及基准工具继续有效，不能将+55功能当作当前产品状态。

版本：1.6.0-preview+55 候选。目标是降低首响和句间空档，聊天模型与语音合成独立选择。本轮没有修改聊天模型权重、提示词或默认离线音色。

## 已实现的接入

- 模型设置新增“AI 语音服务”独立子页，沿用当前主题、字体、材质、圆角和返回路径。默认使用本机离线语音；可选择通义千问在线流式语音。
- 首个在线适配针对 Qwen-TTS-Realtime 的 `qwen3-tts-flash-realtime`，不混用 Qwen-Audio-TTS/CosyVoice 的任务协议。北京/新加坡地域、音色和 AI 朗读语言独立配置；在线暂使用服务默认语速。
- 一个回答一条 WSS 连接，持续追加文字、接收 24 kHz PCM16 单声道音频，再交给现有单轨道播放器；结束后等原生播放头排空才结束说话状态。
- 首个非空文字增量到达后才建立语音连接，模型思考期与空回答不空连，避免长推理时语音服务先超时。
- 云端语音密钥独立保存在 Android Keystore 加密的 `voice-secrets` 命名空间，与聊天凭据分开；公开状态只含 hasKey。没有当前地域密钥或没有明确允许在线合成时不连接。麦克风识别继续本机处理，只上传待朗读的回答文字。
- 网络接收与播放采用有界队列和高低水位背压；取消、切页、暂停和配置变化会失效旧音频。连接、网络无进展、播放停滞和整个会话均有时限。错误脱敏，不输出服务端回显的内容或密钥。
- 独立审查修复了旧 cancel 停止新会话、旧 open 在准备完成后停止新音频、配置入口清除归属却未取消 Host 等竞态；添加会话所有权回归测试。

## 本地对比：性能有替代路线，尚未替换发布模型

OPPO PEHM00，同一 +54 包的 sherpa/ONNX 原生库、CPU 2 线程，语速1.0，固定3条合成中文文本。按 Melo → Matcha → Matcha → Melo 顺序测试，各自先加载并用“你好”预热；没有并行运行两种合成器。只合成测试文本，不录音、不读取用户会话。下表为每项两次均值，首块指原生合成回调，**不是点击到扬声器首响**。

| 中文样本 | Melo 合成/音频 | Matcha 合成/音频 | Melo/Matcha 首块 |
| --- | --- | --- | --- |
| 短句 | 2.929s / 1.867s | 0.631s / 2.331s | 0.844s / 0.222s |
| 连续长句 | 8.707s / 6.049s | 1.513s / 7.105s | 2.978s / 0.523s |
| 两句中文 | 9.101s / 6.188s | 1.585s / 6.528s | 2.278s / 0.374s |

Melo 的合成/音频时长比约1.44–1.57，仍赶不上播放；Matcha 候选约0.21–0.27，证明更轻的本地后端可以有明显余量。但两者音色/语速/声学输出不同，不能把这个比值当作音质等价；没有完成听感、发音覆盖和完整语音聊天验收。候选加载时有 lexicon shei2 警告，必须记录，不隐瞒。

尝试与取舍：

- Melo XNNPACK：当前包未提供该后端，明确回退CPU，不构成加速。
- Melo NNAPI：当前库按API21编译，在该路径回退CPU，不能声称使用了手机NPU。
- Melo 1线程：长句约16.2s/6.0s，更慢，不保留。此前4线程试验也未改善，不重复作为新成果。
- Matcha-icefall-zh-baker：速度有改善，但官方模型卡标记训练数据仅限非商业使用；未打进APK、未改默认模型。用户此前要求许可边界清晰，不能仅凭快就替换。

性能证据：本地 output/speech55/results.json、summary.json、bench-*.log、provider-*.log。模型和 vocoder 为从官方发布地址下载的独立试验数据，未加入产品资源。

## 核验与边界

- Dart 全量251项、浏览器40项、10个现有网页脚本通过；语音JS专项43项。定向分析没有error/warning，仍有既有及部分新增花括号等info级风格提示，不称零提示。
- 在线协议、配置、取消与缓冲均使用本地 fake transport/RPC 测试，**未调用收费API，未用真实语音密钥验收**。
- 浏览器已检查320/390/768/1440宽度与实际截图；手机设置、安装包及构建结果见本轮交接。
- 最终Release构建成功（66秒）；+55已覆盖安装OPPO，版本码55。实测本机默认、切换在线草稿、打开/取消原生密钥框、保存恢复本机、重开确认已保存、逐级返回均正常。没有填写真实密钥、没有打开在线合成许可。
- 真机离线短英文缓存播放完成（1.888s音频/2.086s通道）；中文三段首次生成RTF为1.455/1.548/1.609，13.560s声音对应21.997s通道，11次underrun。语言切换后的首段worker准备7.819s，不能称即点即听。全部提前缓存的重复播放约13.68s通道，但这不是新回复实时效果。再用固定0.8秒间隔点击开始/停止，UI恢复朗读并提示“已停止朗读”，没有把较早已播完后的再次点击误记成停止。截图与元数据日志在output/speech55，不等同外放听感验收。
- 本机实时中文仍未达标；新的在线通路也只有完成真实服务、网络与设备验证后，才能称实时语音聊天验收通过。存储损坏时保留原配置；Host有显式重置方法，但本轮未提供恢复按钮。
