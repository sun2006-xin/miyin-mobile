# 全球本地语音范围与引擎选择

用户本轮确定：普通翻译/面对面翻译朗读先保留现有方案，AI语音聊天使用新快速方案；ASR按速度与准确性优先，允许减少语言数量，但不能只覆盖中英或五种语言。ASR/TTS本地运行，外接API只增强聊天能力。

先作为验收目标（未代表已实现）：中、英、日、韩、俄、法、德、西、葡、意、阿、印地、印尼、越、泰、土耳其16种。保留其他已有可尝试语言，不将其标为已验收快速语言。分别记录ASR与TTS覆盖，不能用翻译文字支持列表冒充语音支持。

TTS：AI中文优先Matcha候选；非中文用已有Supertonic3覆盖31语言，英文再比较。Matcha只有中英单音色，禁止全局替换翻译朗读。用户不需要管理引擎，应用内部按已选语言/回复语言调度。保留预热、内存、冷切换测量，不能同时无条件常驻全部引擎。

ASR候选顺序更新：Qwen3-ASR-0.6B应纳入统一多语候选，与当前Whisper base比较。官方支持30语言+22中文方言，Apache2；本地sherpa1.13.8头文件有OfflineQwen3ASR配置，官方Flutter已有Android文件识别示例。这些仅证明接入路径存在，未证明OPPO可实时或官方流式实现可原样移植。SenseVoice5语种作为快速候选，不能成为唯一引擎；Whisper small作为广覆盖准确性对照。Moonshine部分语言有原生流式，但缺少部分主要目标语言，不用多模型叠加冒充单一全覆盖方案。

隐藏问题验收：首次离线可用、跨语言冷切换、后台恢复、尾句/打断、TTS回声误识别、短句语言判断、数字/姓名/混说、长时间发热、与本地聊天模型并发、资源完整性与旧设备后备。不能承诺一次选型永久解决所有设备/语言。无新APK、未完成Qwen/其他新ASR真机性能测试。
