## 修复

1. 原先联网资料要求模型标注 `[网页N]`，Markdown 渲染却只处理 `[资料N]`。现分别映射：网页打开该回答对应的来源，资料继续定位用户选中的本机资料。
2. 引用渲染缓存加入当前来源地址，解决正文先到、来源后到或来源更换时旧渲染残留的问题。重新生成时先清空上一轮网页来源；请求编号仍隔离过期结果。
3. 实际搜索核验发现搜索 HTML 超过普通网页的 512 KiB 限制。搜索内部 raw/feed 路径调整为 2 MiB，有界累积，解析前再次检查；普通网页导入仍是 512 KiB。保留原 TLS 校验、公开地址限制和取消行为。
