# 本地中文 TTS 候选真机对照（speech57）

本轮完成候选引擎的独立真机性能筛选，未替换应用中的 Melo，未打新 APK。OPPO 仍为 1.6.0-preview+56。所有输入均为开发者准备的普通中文文本，没有读取用户会话、调用麦克风或云语音 API。

## 固定条件

- OPPO PEHM00，Android 12，arm64；同一组 APK 提取的 sherpa-onnx 1.13.8 / ONNX Runtime 库。
- CPU 2线程、speed=1，先用“你好。”预热，再测三段相同文本。每个候选独立进程。
- Melo→Kokoro→Kokoro→Melo 为 ABBA；AISHELL3 一轮；Matcha zh-en 两轮。不同音色发音时长不同，不能只用合成耗时比例说明主观语速或音质。
- 首 PCM 是独立 C API 回调，不是点击到扬声器首响；没有覆盖聊天模型推理竞争、应用播放器、停止、切换、多语言及长会话。

## 结果

下表取第二段文本：“我们正在测试连续语音播放，希望说话自然流畅，不要在每一句之间停下来等待。”

| 候选 | 采样率 | 合成耗时 | 首PCM | 音频时长 | RTF |
| --- | --- | --- | --- | --- | --- |
| 当前 Melo，两轮 | 44.1kHz | 8.703 / 8.713秒 | 2.977 / 2.978秒 | 6.049秒 | 1.439 / 1.440 |
| Kokoro int8，两轮 | 24kHz | 18.049 / 18.045秒 | 6.332 / 6.349秒 | 6.993 / 6.997秒 | 2.581 / 2.579 |
| AISHELL3 VITS，一轮 | 8kHz | 0.930秒 | 0.877秒 | 9.936秒 | 0.094 |
| Matcha zh-en，两轮 | 16kHz | 1.131 / 1.133秒 | 0.402 / 0.404秒 | 6.905 / 6.904秒 | 0.164 / 0.164 |

RTF小于1表示这组条件下合成快于播放。Matcha的第三段也稳定在约1.202秒合成/6.745秒音频。Kokoro不作为本轮加速方向；AISHELL3有速度优势但8kHz音质和数据许可口径需单独评估，暂不默认替换。

## Matcha可推进边界

优先继续验证 `matcha-icefall-zh-en`，不是此前非商业限制的 `matcha-icefall-zh-baker`。模型卡指向作者的 `matcha_tts_zh_en_20251010`，16kHz、单音色。作者 ModelScope 元数据声明 Apache2；完整训练数据来源未公开，不能把运行时许可当作模型或数据许可。

- 模型卡：https://huggingface.co/csukuangfj/matcha-icefall-zh-en/blob/main/README.md
- 作者：https://modelscope.cn/models/dengcunqin/matcha_tts_zh_en_20251010/summary
- 声学包：79,033,838字节，SHA256 `271b804af570400d3bcdcb53bf6e53cc9f75180ee763b9f13eb5eaf2b0d086ef`
- 独立16k声码器：53,882,848字节，SHA256 `b599142a1fb8ff03de3e84ac35ff537c619e56f4267a6fe894851a42844acf9e`

官方前端要求 eSpeak dataDir。本轮传入现有真实数据目录后中文成功，不能由此断言去eSpeak依赖、英文回退或发行边界已完成。下一阶段需核验当前原生库实现和前端适配，不能用空文件绕过校验。英文可继续使用现有Supertonic，其他语言保持既有实现。
