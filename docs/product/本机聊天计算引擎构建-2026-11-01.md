# Reproduce the Android shared CPU dispatch server

Upstream: https://github.com/ggml-org/llama.cpp

Fixed revision: `d854d98bae598388ecea1ed84396587e5edc326d`. Configure from a clean ignored build directory with no preexisting UI dist. NDK 28.2.13676358 supplies Clang 19.0.1. CMake 3.22.1 and Ninja are used; max parallel is 4.

Run from the fixed source checkout, with PowerShell:

```powershell
 & "D:/DevTools/android-sdk/cmake/3.22.1/bin/cmake.exe" -S . -B build-android-dispatch47 -G Ninja `
  -DCMAKE_MAKE_PROGRAM=D:/DevTools/android-sdk/cmake/3.22.1/bin/ninja.exe `
  -DCMAKE_TOOLCHAIN_FILE=D:/DevTools/android-sdk/ndk/28.2.13676358/build/cmake/android.toolchain.cmake `
  -DCMAKE_BUILD_TYPE=Release `
  -DANDROID_ABI=arm64-v8a `
  -DANDROID_PLATFORM=android-28 `
  -DBUILD_SHARED_LIBS=ON `
  -DGGML_BACKEND_DL=ON `
  -DGGML_CPU_ALL_VARIANTS=ON `
  -DGGML_NATIVE=OFF `
  -DGGML_CPU_ARM_ARCH= `
  -DGGML_OPENMP=OFF `
  -DGGML_CPU_REPACK=ON `
  -DGGML_LLAMAFILE=OFF `
  -DGGML_LTO=OFF `
  -DLLAMA_BUILD_COMMON=ON `
  -DLLAMA_BUILD_TOOLS=ON `
  -DLLAMA_BUILD_TESTS=OFF `
  -DLLAMA_BUILD_EXAMPLES=OFF `
  -DLLAMA_BUILD_SERVER=ON `
  -DLLAMA_OPENSSL=OFF `
  -DLLAMA_BUILD_UI=OFF `
  -DLLAMA_USE_PREBUILT_UI=OFF `
  -DLLAMA_BUILD_MTMD=OFF
& "D:/DevTools/android-sdk/cmake/3.22.1/bin/cmake.exe" --build build-android-dispatch47 --target llama-server --parallel 4
```

Both UI flags must be OFF before the first server build to prevent network provisioning. If reusing a directory that already downloaded UI assets, these flags alone do not remove stale assets: the official script reuses dist/index.html. Archive only that generated build/tools/ui/dist outside the active dist path before rebuilding; do not change upstream source. The final build log must report 0 embedded assets.

GGML_CPU_ALL_VARIANTS creates all official Android variants, while the delivered package intentionally contains only armv8.0 fallback and dotprod+FP16 armv8.2_2. Do not add i8mm/SVE/SME modules without separately validating them. CPU feature score objects are baseline-compiled with -fno-lto.

The official server has a required mtmd library dependency even when the standalone MTMD tool option is OFF. It is part of the audited dependency closure; no vision model is bundled or used by these tests.

Copy only the nine ELF artifacts listed in manifest.json from build/bin into a fresh package directory and strip the copies with the same NDK llvm-strip.exe --strip-unneeded. Keep build outputs with debug symbols outside the package. Preserve shared-library and CPU-module basenames. Rename only the executable llama-server to libmiyin_llama.so when placed into Android jniLibs. Set LD_LIBRARY_PATH to nativeLibraryDir when launching this standalone ELF. ELF interpreter is /system/bin/linker64; system libraries libc.so/libm.so/libdl.so are provided by Android.

Artifact SHA256, NEEDED closure, empty RUNPATH, exact flags, and copied license notice hashes are in build-manifest.json. Upstream MIT LICENSE and available standalone vendor/ggml notices are copied under licenses; additional source-header license provenance remains at the fixed upstream revision. No model weights or keys are included.

HTTP app-default validation uses only -m MODEL -c 4096 -t 4 -np 1 --host 127.0.0.1 --port 11439; batch/ubatch/GPU-layer/reasoning server options remain revision defaults. Thinking is disabled only per request via chat_template_kwargs.enable_thinking=false. The earlier explicit b128/ub128/ngl0/global-reasoning-off HTTP series is withdrawn from app-default comparison and retained separately as controlled diagnostics. Standalone bench ABBA b128/ub128/ngl0 remains a valid separate experiment.
