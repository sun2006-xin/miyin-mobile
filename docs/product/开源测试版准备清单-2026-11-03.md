# 开源测试版准备清单

状态日期：2026-11-03。范围：先分享可体验的翻译/同传/AI对话，不把完整手机Agent或所有语言完善作为前置条件。此清单不是已经发布的声明。

## 当前可以做什么

已有可安装Android开发候选包，翻译、同传录制和AI普通对话均有实现与阶段验证。preview65已在OPPO完成34段长回答朗读、停止、离开页面验证；用户反馈连贯性明显改善，首次英文仍需优化。其他品牌与全部语种尚无同等覆盖。

## 正式开源和公开APK前的收尾

- [ ] **确定应用源码许可证。** 当前没有根LICENSE，必须由项目所有者确认后添加；公开仓库本身不替代授权。
- [ ] **闭合随APK分发的第三方材料。** 逐项核对原生库、eSpeak数据、模型权重与派生文件的完整许可、来源、对应源码/构建资料要求；已知边界见`app/miyin/THIRD_PARTY_NOTICES.md`。不能只看某个模型标为Apache就判定整包完成。
- [ ] **核对拟公开内容。** 检查公开快照及计划公开的提交范围中的密钥、个人配置、设备数据和版权不明材料；当前按文件名检查未发现已跟踪.env/keystore，不等于内容与历史检查完成。
- [ ] **全新目录按文档构建。** 完整取回LFS对象，明确工具链、Gradle wrapper生成/提供方式、模型来源与构建命令，完成一次不依赖本机未跟踪文件的构建。现有开发机能构建不能替代此项。
- [x] **更新明显过时的入口说明。** 根与应用README已改为当前preview能力和验收边界，移除未跟踪output截图链接；文档仍需随上述干净构建结果补充。
- [ ] **确定分享版本和升级策略。** 当前APK约2.24GB、沿用Debug签名。公开测试版应明确设备要求、包大小、已知问题、反馈入口和更新方式；长期固定发行签名另行准备，不在仓库保存私钥。

## 可以逐步完善，不必拖住首次公开体验

- CI与贡献指南、问题模板、跨手机验收矩阵。
- 更多语种的准确率与发音评估。
- 更快的冷启动、更轻的分包或安装体验。
- 更完整的工具调用/手机Agent能力。

## 判定方式

核心功能达到可接受体验，源码许可、资源分发材料、拟公开内容检查和全新构建有证据时，即可进入开源测试版发布。首版公开时同时说明缺口；不把开发候选包称为全设备、全语言成熟版本。本轮没有推送、改变仓库可见性或公开发行。
