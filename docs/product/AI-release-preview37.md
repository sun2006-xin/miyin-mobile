# AI 聊天体验版 +37 发布说明

本版整合此前 AI 聊天、模型配置、隐私与外观增量，不变更翻译和同传的产品范围。

## 软件与模型的责任边界

软件核验配置保存、模型显示名单、请求构造、流式显示、取消、上下文预算、历史和运行时复用。模型的知识、错误答案和拒答不通过硬编码问答、补知识或训练修补，也不作为软件发布阻断项。用户可以替换模型。

## 获取与构建

先安装 Git LFS，再执行 `git lfs pull`。聊天权重位于 `app/miyin/assets/chat-model/model.gguf`，模型及运行时许可在同目录，原生 ARM64 运行时已随源码提供。

在 `app/miyin` 执行 `flutter pub get`，然后 `flutter build apk --release --target-platform android-arm64`。版本由 pubspec.yaml 的 `1.6.0-preview+37` 指定。构建需要匹配 pubspec 的 Flutter/Dart、Android SDK、JDK 与网络依赖缓存。

本版 APK 包含本机聊天与语音资源，因此文件较大；仅提供 ARM64 Android 体验安装包，沿用现有体验签名。仓库中的开发设备地址、密钥、录音、截图与构建缓存不得纳入发布。

## 核验边界

前序 +37 已完成 OPPO 安装、本机运行时连续请求、取消及短暂后台复用检查。本轮 150 项 Dart 测试、全部 10 个前端测试脚本、5 项原生保温策略检查和 Android Release 构建通过，APK 内 64 个资源与当前文件一致。聊天静态分析无错误或警告，保留 68 项风格提示。仓库当前无远程 CI 工作流。不会将模型答题表现写成软件正确性证明；云厂商真实 API Key 调用仍由后续联调验证。
