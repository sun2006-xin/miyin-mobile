# 觅音品牌启动动画概念 v0.1

状态：图标视觉方向已确认；动画节奏、动效细节和宣传语待后续预览确认。

## 动画顺序

1. 白色玻璃质感底块显现，用户确认的抽象黑色线条唇形标志出现，不画脸部或口红，也不做写实填色。
2. 嘴唇发声，黑色声线向左舒展并优雅弯曲。
3. 声线在左侧自然带出若隐若现的耳形，形成“听见”的视觉反馈。
4. 动画收束后显示品牌名“觅音”。
5. 品牌名下方显示宣传语；具体文案待用户确定。

## 视觉边界

- 以简洁、清晰、轻量为目标，优先让声音从嘴唇传到耳朵的因果关系一眼可读。
- 动画沿用 [用户确认的图标 PNG](miyin-icon-approved-v1.png)：白色玻璃底块、朝左的抽象黑线唇形和渐成耳形的声线。PNG 是当前视觉基准，动画仍待单独预览确认。
- 用户已确认图标视觉方向；PNG 尚未导出为 Android 启动器资源，动画仍需单独预览确认。
- 不在动画中自动播放声音；动画表现“发声”使用视觉声波即可。
