## 本轮发现并修复

1. OPPO 对 raw.githubusercontent.com 的连接被重置，GitHub 下载页也有超时。清单改走官方 Contents API，分卷走官方附件 API；没有引入第三方镜像或分发密钥。
2. 周期任务首次执行与启动检查可能重叠：周期首次延迟 12 小时，下载队列决策串行执行。
3. 升级时旧网络重试的退避队列阻挡新检查：版本变更后替换旧的立即检查任务；75 真机启动已验证实际执行成功。
4. 云端完整包构建曾磁盘不足：清理不用的模拟器、工具及已完成检出的重复 LFS 缓存后重建通过。
5. README 下载入口指向未发布的中间版本，封板时统一为 preview75。

## 验收边界

本轮没有完成“未来新版出现 → 后台下载完整约 2.23 GB → 用户授权或确认 → 系统自动覆盖安装”的完整跨版本连续验收。已验证实际更新检查、附件分段传输、完整包摘要与覆盖安装；这些证据分别记录，不替代尚未完成的连续流程。

尚未扩展到其他手机品牌、所有语种识别质量、外接付费模型服务的真实请求。Android 可能要求一次性安装授权及系统安装确认；GitHub 匿名 API 的访问和限流仍受用户网络条件影响。
