# 觅音 V1.5.1+13

发布日期：2026-10-25。Android arm64 体验包，沿用现有调试签名。

## 更新

- 新增统一的「觅音外观」入口，主题、按钮/字体、AI 球体按分类选择并逐级返回，系统返回键同步支持。
- 新增云玉雾玻主题及按钮材质、触感、字体组合；保留旧用户主题选择。中文标题字体随包提供，许可见第三方声明。
- 修复旧 Android WebView 下材质和边框消失；同传语言方向、开始按钮、记录操作和离线资源入口跟随当前主题。
- 同传状态文字与字幕样式、开始按钮对齐；底部记录操作等高并排，移除音源白色勾选装饰。
- 翻译输入框采用柔和主题边界；字幕历史长文本与录制文件名限制在屏幕内显示。
- 包含此前 V1.5.0 的内置语音资源、同传字幕、双声源有声 MP4 和独立原声 WAV 保存能力。
